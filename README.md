# monitoramento-rollout-escalonado

Este repositório contém os códigos e materiais utilizados no desenvolvimento do Trabalho de Conclusão de Curso, que propõe e avalia uma metodologia para monitorar a entrega de valor em projetos de tecnologia implantados de forma escalonada. A abordagem utiliza a trajetória histórica individual das carteiras como referência, agregação temporal por janela móvel e regressões lineares nos períodos pré e pós-implantação para identificar alterações na tendência.

O estudo é conduzido por meio de dados sintéticos, permitindo controlar o processo gerador dos dados e conhecer o efeito verdadeiro introduzido em cada carteira. A metodologia é avaliada pela capacidade de identificar corretamente a direção do impacto, considerando diferentes combinações entre a tendência natural das carteiras e o efeito da implantação.

O repositório contém o código de simulação em R, procedimentos de agregação e modelagem, análises estatísticas e resultados utilizados na avaliação da metodologia.
